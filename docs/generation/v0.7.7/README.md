## What's new
Replace scenario accumulation with a coherent professional procedure: understand
the job and evidence, investigate material context, form and challenge a diagnosis,
make a decision, communicate and verify. Ask only consequential unresolved choices.
Put the useful result first; keep supporting material available and decisive
uncertainty visible. These requirements do not mandate six Structure cards,
unlimited research, a word quota or a new schema.

See [decision continuity](DECISION_CONTINUITY.md),
[integration delta](HARNESS_DELTA.md) and [validation](VALIDATION_REPORT.md).

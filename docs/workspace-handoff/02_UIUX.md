# Workspace and interaction specification

Use M2's warm paper, rust accent, serif headings and system body fonts. Extend its tokens rather than create a competing visual language. No downloaded fonts, decorative scores or dense nested dashboard cards.

Desktop: persistent task list, task title/status, four work-area controls, a focused content region. Narrow screens: compact task selector and wrapping area controls; readable single column without page overflow. Areas remain viewable; individual actions explain prerequisites. No automatic redirects or provider calls on reopening.

Inputs preserves current M2. Reference has saved asset/status, player, explicit Analyze, sample entry, sampled visuals and chronological speech/text. Reading comes first; clicking Correct reveals allowlisted fields. A sample point must never look like an exhaustive continuous shot section. Roles are interpretations. Expanded source details explain coverage and uncertainty; internal IDs are not primary copy.

Directions compares idea, Hook, narrative, brand fit and resources. Details reveal editable current text and timestamped evidence. Expanding a card is not selection. Selecting is not approval. Manually changed text carries a clear old-auxiliary notice; user approval is allowed after review without forcing AI.

Production presents readable brief and timed rows with focused text editors, explicit save and explicit regeneration. Original suggestions and cited reference elements are distinct. Export has visible saved/current/historical status. Dirty export offers Save and export or Cancel; PDF opens a saved-document print view with visible native print instructions.

All editors show loading/saving/draft saved/applied/conflict/error distinctly. Persist drafts before task/area changes. Keep newer typing while responses arrive. Deleted source links are not active. Retain historical results behind contextual disclosures.

Semantic labels, keyboard activation/focus, associated errors, restrained live announcements and reduced motion are required. Validate desktop and 390/320px widths, actual long bilingual content and print pagination. The conversational structural wireframe was approved; actual rendered screens remain subject to agent inspection and subsequent human acceptance.

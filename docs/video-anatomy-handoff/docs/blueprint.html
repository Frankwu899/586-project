Plain-English vocabulary

Skeleton

A runnable set of connected modules. The baseline can use labeled sample results while real providers are added.

Data contract

The exact shared fields and rules every producer and consumer must follow. Executable checks catch incompatible values.

Dependency

Information or functionality another feature needs. For example, direction generation needs a confirmed analysis and a brand brief.

Evidence event

One visible or audible observation during a source frame range. Its role and likely creative usefulness are separate interpretations.

Timing rule Andrea must preserve

Source evidence uses [start_frame, end_frame).

The start is included and the end is excluded. [60, 65) covers five frames. Require integer values with 0 ≤ start_frame < end_frame ≤ frame_count. Events may overlap; primary sections must be ordered and nonoverlapping. A cited event must overlap its section.

  • VideoAsset.frame_timing records rational FPS, decoded frame count, rate mode, actual frame boundaries and media start time. Use measured values, not an assumed 30 fps.
  • If a provider returns seconds, use backend/app/timing.py::seconds_to_frame_range and validate the converted intervals and references.
  • Use actual presentation boundaries for playback. HH:MM:SS:FF display is nominal non-drop-frame and approximate for fractional/variable rates; this is review support, not a frame-perfect editing/export guarantee.
  • Storyboard rows continue to use start_seconds/end_seconds and the brief’s target_duration_seconds. Reference FPS does not set an output FPS.
  • Missing or changed legacy media must retain explicit legacy timing and invalidate affected creative use rather than invent a frame map. Original v0.2 payloads are archived during migration; v0.1/v0.2 schemas/examples remain historical snapshots.

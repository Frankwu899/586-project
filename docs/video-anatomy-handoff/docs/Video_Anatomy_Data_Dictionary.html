08 · VALIDATION & OPEN DECISIONS

怎样判断这份协议能让各模块独立开发

  • 字段完整性：本字典自动核对当前源模型的字段及继承关系；现有与拟新增分别展示。
  • 时间合法：帧区间严格为整数且 0 ≤ start < end ≤ frame_count；实际时间映射正确；来源帧和计划秒数分离。
  • 引用合法：同任务、同视频、精确分析修订；事件和主体编号存在，段落引用的事件有时间交集。
  • 缺失诚实：0、null、[]、not_analyzed、none_found、failed 含义不同；不得用猜测值填满数据。
  • 来源与版本：保留原始分析；内容纠正追加修订；真实、人工、样例来源不能混淆。
  • 产品门槛：当前的成功、确认和批准规则保持；新增标签失败的影响先作为产品决策，不偷偷放宽。
  • 验收分两种：格式、时间、引用由自动检查；内容识别准确率与创意帮助程度由真实素材和人工标注评估。
设计状态与实施默认本稿建议为何重要
新增类别与字段是否满足目标先采用主体／动作／产品展示三组；保留自然语言描述与 null。决定第一版结构化范围。
结构化标签纠错：已确认允许；保留原始结果、追加修订、清除确认并使下游失效。这是已确认需求；现有 v0.3 接口仍需扩展。

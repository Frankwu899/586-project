## Changes to test

- Overview validates the reply and each brief proposal separately. Safe discussion
  and independent valid proposals survive a rejected item; unsupported claims and
  citations remain blocked. Incomplete extraction is visible and never applies
  the brief automatically.
- A failed turn has an explicit retry using its saved user message. Completed
  turns cannot silently replay; interrupted work waits for an explicit retry.
  Newer brief edits continue to invalidate delayed responses.
- Speech processing retains completed chunks and valid timestamped segments,
  records incomplete coverage, and retries missing work without repeating
  successful visual extraction. Small boundary rounding is bounded and reported;
  genuinely invalid timing remains unavailable evidence.
- Prepared audio is checked for actual samples, duration, format and alignment.
  Unsupported tracks and limits remain actionable preflight failures. Empty
  provider output is described as no speech detected, not proof of silence.
- Credit exhaustion, enforced spend/usage limits, temporary throttling,
  authentication, permissions, output validation and processing failures have
  distinct diagnoses. Models lookup explicitly does not test paid inference,
  transcription permissions or available billing.
- Expandable support details can be copied or downloaded. They include operation
  correlation, application/source identity and validation/chunk outcomes, excluding
  keys, authorization headers, full prompts, source text and raw media by default.

## Install, preserve work and roll back

1. Stop the previous app and back up the entire library while it is closed.
   The default Mac location is `~/Library/Application Support/Video Anatomy/`.
   Preserve databases, source files, evidence, corrections and output history.
2. Extract the supplied ZIP fully. For the Mac ZIP, read `READ ME FIRST.md` and
   open `Video Anatomy.app`. Python 3.12 and FFmpeg/ffprobe must be installed;
   first launch installs pinned Python dependencies over the internet. Node is
   unnecessary for the prebuilt UI. Optional document OCR uses Tesseract/Poppler.
3. For the local ZIP, open `Start Video Anatomy.command` on macOS or follow
   `LOCAL_API.md`. An existing custom library can be opened with
   `bash scripts/start-local.sh --data-dir "/absolute/path/to/library"`.
4. Verify **1.8.2** and the same source commit in About on every tester's machine.
   `PACKAGE_MANIFEST.json` records that exact commit and all packaged file hashes.
   Use the separately delivered ZIP SHA-256 to check the complete download.
5. Open saved projects and inspect their existing results before making new paid
   requests. Do not delete data or retranscribe merely to open a project.

Project schema family remains 1.8.0 with additive defaulted diagnostic and turn
correlation fields. No destructive migration is required. Older binaries may
reject newly stored fields: rollback with the old app and a **separate copy of
the pre-upgrade library backup**, keeping the newer library intact.

The Mac ZIP is an unsigned dependency-assisted Finder launcher, not a
self-contained or notarized DMG. Linux package checks do not establish macOS
Gatekeeper, Keychain or installation behavior.

# Video Anatomy 1.8.3 — Mac testing candidate

This is the integrated local workspace candidate for Frank's acceptance. It is
not a signed release, a self-contained DMG, or a claim of live model quality.

## What changed

- Overview prepares a reviewable Brief without a required-field interview. It
  asks at most one consequential question per turn, defaults to at most two
  proactive turns, and respects an explicit request to proceed. Send becomes
  Stop in place. Retry uses the saved message and a new attempt; late callbacks
  cannot overwrite stopped or newer work. Applied Brief changes stay explicit.
- Resources opens as a Media Pool with real logical folders: Inbox, References,
  Documents and Production Assets. List/grid, rename, move and recoverable Trash
  preserve original bytes and source identities. File focus is separate from
  selection; analysis starts only after its exact media/scope confirmation.
- Source Review combines original playback, one playhead, recorded evidence
  tracks, transcript search, corrections and recovery. Historical citations open
  exact saved revisions. Unknown or conflicting historical data stays explicit;
  a valid source-only range never borrows current evidence.
- Analysis leads with distinct source-linked Key insights, followed by comparison
  and a readable graph or ordered list. Browsing reports does not switch the
  planned production Video. Explicit inspiration adoption preserves source links.
- Content plan defaults to a standalone Video. Series is optional; topic previews
  create a plan entry only through Add to plan. New original videos do not
  inherit project references. Reference selection and direction approval are
  explicit, with formal evidence and context gates retained for generation.
- Production remains a separate tab on that same Video. Its main deliverable is
  a short Production brief plus one editable eight-column Storyboard Sheet,
  one row per shot. Save, reopen and export use the same structured revision.
  CSV splits planned Start/End into numeric columns and contains no manifest or
  supporting-reference rows. Legacy free-text documents and historical exports
  remain available without guessed shot rows.
- Projects retains independent duplication and recoverable Trash, with recent
  openings, search and keyboard-accessible dialogs. Navigation and controls wrap
  in narrow windows. Discover is reserved with a local Resources entry point.

No crawler, downloader, editor, renderer, generated video, publishing service,
model migration or billing change is introduced. The application baseline remains
`gpt-6.1-sol`, with separate timestamped `whisper-1` transcription.

## Install and preserve 1.8.2 work

1. Finish running work, stop the old app, and back up the complete library while
   closed: `~/Library/Application Support/Video Anatomy/`. Keep all databases,
   originals, evidence, corrections, approvals and exports together.
2. Extract the single Mac test ZIP. Its top level contains only `README.txt` and
   `Video Anatomy.app`. Read the instructions and open the app. Python 3.12 and
   FFmpeg/ffprobe are required; first launch installs pinned Python dependencies
   over the internet. Node is not required for the prebuilt UI.
3. Confirm version **1.8.3** and the delivered source commit in Settings. The
   internal `PACKAGE_MANIFEST.json` records the exact clean source and hashes.
4. Open an existing project before starting paid requests. Keep an earlier
   custom data directory unchanged if one was used; follow README instructions
   rather than merging SQLite files or deleting a library.
5. Keep the old package and backup. Additive project fields can be rejected by
   older binaries: rollback with a separate copy of the pre-upgrade backup,
   keeping the newer library intact. Keychain service and client usage behavior
   are unchanged.

The launcher is unsigned and dependency-assisted. Linux checks cannot establish
Finder, Gatekeeper, signing, Keychain or actual macOS browser behavior. Optional
scanned-document OCR still needs Tesseract/Poppler; complex and unsupported input
formats retain their documented limitations.

## Morning acceptance checklist

- Launch on the Mac; confirm version/commit, Keychain connection and the expected
  old library. Open an old project without re-uploading or re-analyzing it.
- Try a concise real assignment: zero/one/two clarification turns, Stop/Retry and
  explicit Brief review. Check actual provider output and account permissions.
- Move/rename/restore a file; open historical and current evidence, follow an
  Analysis timestamp and confirm the original media moment. Check speech quality
  on representative media rather than treating synthetic tests as accuracy.
- Approve a Video direction, edit a shot, save/reopen, and compare the exported
  sheet with that exact saved revision. Try narrow windows and browser zoom.

Use the existing team feedback sheet with version/commit, browser/zoom,
reproduction, expected/actual result and evidence. No new tracking system,
merge or public release is implied by this candidate.
